# HPC Coordinator Project

Multi-repo coordinator for HPC infrastructure, OpenHPC development, and Warewulf contribution.
See `docs/workspace-design.md` for the full design rationale.

## Claude Code Settings

`.claude/settings.json` (tracked in git) configures permission allowlists for this project.
See `docs/claude-code-settings.md` for permission pattern syntax, `ssh://` URI gotcha,
`autoMemoryEnabled`, and notes on the `update-config` skill.
